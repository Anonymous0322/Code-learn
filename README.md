# CodeLearn

## Programming Learning Platform

Learn programming from absolute zero in your language — Uzbek, Russian, or English.

### Quick Start
```bash
# Clone and setup
git clone <repo-url>
cd codelearn
./scripts/setup.sh
npm run dev
```

### Features
- 🚀 Learn HTML, CSS, JavaScript, Python and more
- 🌍 Multilingual interface (Uzbek, Russian, English)
- 🎯 Interactive code playground
- 📊 Track your progress and earn achievements
- 🏆 Build real projects as you learn

### Tech Stack
- Next.js 14 + TypeScript
- PostgreSQL + Redis
- Docker-based code execution
- Tailwind CSS + Framer Motion
